## What is Pixie?

Pixie is a LED circuit PCB project created as part of Hack Club's Half Life program.

My original idea was to create a small interactive OLED pet, but due to time constraints and challenges with circuit design, I decided to simplify the project into a basic LED circuit.

This project helped me practise the fundamentals of electronic circuit design and PCB layout using KiCad.

## How It Works

The circuit uses a simple LED, a resistor, and a screw terminal.

- **LED:** Produces light when current flows through it.
- **Resistor:** Limits the current flowing through the LED to help protect it.
- **Screw Terminal:** Provides a connection point for the power supply.

## Components

| Component | Quantity | Purpose |
|---|---:|---|
| LED | 1 | Produces light |
| Resistor | 1 | Limits current |
| Screw terminal | 1 | Connects the power supply |
| PCB | 1 | the base|

## Design Process

I designed the circuit schematic and PCB layout using KiCad.

I learnt
- Creating electronic schematics.
- Selecting component footprints.
- Placing components on a PCB.
- Routing copper traces.
- Running ERC and DRC checks.
- Generating Gerber and drill files.
